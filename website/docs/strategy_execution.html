추진 전략 & 수행 개요 / Strategy & Execution

세부 목차 / Section Outline

  1. 데이터셋 구축 로드맵 (표준연 코퍼스)
  2. 글로벌 ↔︎ 표준연 매핑 전략
  3. 모듈 간 연계 및 역할 정의
  4. 포트폴리오/대시보드 패키징

킥오프 덱의 전략을 현재 파이프라인에 맞춰 재정리했습니다. 키워드·클러스터 처리는 전체 흐름의 한 단계이며, 이후 국가/기관 벤치마킹과 포트폴리오 설계까지 이어집니다.

Integrated Flow / 통합 연계 구조

  1. 데이터셋 구축: 표준연 키워드, BIPM 기관 리스트, 핵심 저널, 인용 확장으로 WoS 기반 코퍼스 수집·정제.
  2. 글로벌→도메인 맵: 전체 코퍼스 유사도 기반 글로벌 맵 생성 후, 표준연 서브셋을 Leiden 클러스터링해 도메인 맵을 만들고 Overlay로 분포를 확인.
  3. 유망영역 평가: 클러스터별 성장성·파급성(지식확산)·영향력(엑셀런스)·산업연계성 지표를 계산하고 가중치 기반으로 유망영역을 선별. (키워드/시계열 파이프라인이 여기에 연결됨.)
  4. LLM 리포팅: 정의·필요성·동향·키워드·핵심문헌을 템플릿화한 간이 리포트를 LLM으로 생성.
  5. 성과/벤치마킹: 국가·기관별 엑셀런스 백분위 + 상위분위수 점유율(규모)로 비교, 추이 분석.
  6. 프로파일/협력 네트워크: 공저 네트워크와 Overlay 맵으로 기관별 포트폴리오·공백 영역을 시각화.
  7. 포트폴리오·배포: 데이터북/대시보드에 통합해 전략 시나리오와 모니터링으로 이어짐.

Pipeline Responsibilities / 파이프라인 역할

  • Data Engineering: 인입·메타데이터 정제·희소집계(Leiden/맵 대비), Stage 0–1.
  • Keyword/Cluster Intelligence: 스코어링, 중복 억제, 정규화, 시계열(Stages 2–3).
  • Indicator Stack: 성장/확산/영향/산업연계/엑셀런스·점유율 조합, AHP/정책 가중치 적용.
  • LLM 지원: 클러스터/세부영역 서술 템플릿, 품질체크와 캐시 관리.
  • 시각화/배포: Overlay 맵, 협력 네트워크, 벤치마킹 대시보드, 데이터북.

구현 세부는 Pipeline Architecture & Flow를 참고하세요.

Governance Hooks / 거버넌스 포인트

  • Checkpoint Review (월별): Validate cluster quality, indicator behaviour, and LLM summaries.
  • 분석 블록 (격주): Module 1 vs Module 2 teams share discoveries to keep emerging-area insights aligned with benchmarking outputs.
  • 사전 킥오프 산출물: Scope definitions, success metrics, schedule baselines, and documentation plan (this site + dashboard roadmap).
