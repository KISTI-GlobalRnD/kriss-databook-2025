## LLM 기반 유망 연구 간이 리포팅

본 사업에서는 유망 연구영역 후보를 비교·검토하는 과정에서, 클러스터 단위 요약을 동일한 템플릿으로 반복 생성할 필요가 있었다. 이에 따라 용어·범위·표현의 변동을 줄이기 위해 간이 리포팅 템플릿을 고정하고, 동일한 구성으로 요약문을 생성하였다.

본 사업에서는 유망영역으로 선정된 30개 클러스터를 더 자세히 검토할 수 있도록 “간이 리포팅”을 자동화하였다. 간이 리포트는 클러스터별로 그림을 포함해 약 10쪽 내외의 분량으로 구성하였으며, 핵심 지표·연결 구조·키워드·기관·정책부합성 정보를 동일한 양식으로 정리하였다.

간이 리포팅의 기반이 되는 수치·분포·시각화는 대부분 대시보드에서 확인할 수 있는 내용이며, 본 절에서는 이를 서술형 텍스트와 표 중심으로 재구성하였다. 대규모언어모델(LLM; large language model)은 이 과정에서 프롬프트(작성 지침)와 API 호출을 통해 문장 구성과 용어 설명을 보조하는 수준으로만 활용하였으며, 수치·근거는 입력 데이터 범위 내에서만 기술하도록 제한하였다.

간이 리포팅의 입력·출력 구성, 지표·키워드 해석 원칙, LLM 활용 범위와 안전장치, 유형별 독해 가이드는 부록의 **상세 리포팅 방법론**에서 별도로 정리하였다. 본 절에서는 전체 프로세스의 목적과 활용 범위를 간략히 소개하였다.
