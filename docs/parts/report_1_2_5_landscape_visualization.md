## 표준과학 연구지형도 시각화

지금까지 도출한 표준과학 연구 분야 문헌 집합에 대한 클러스터링을 기반으로한 연구지형도를 기반 맵(base-map)으로 하였다. 이 때 클러스터별 4대 영역 매핑 결과는 물론, 개별 클러스터의 성장성, 파급력, 기술진보 기여도 등 과학계량학 기반 유망성 지표와 주요 벤치마킹 연구기관의 세부 연구영역별 역량과 특화도 등 이어지는 주요 기관별 포트폴리오 분석 및 유망연구영역 선정에서 상세히 다룰 지표들을 겹치기 맵(Overlay map) 기법을 이용하여 시각화하였다.

글로벌 연구지형도와 마찬가지로 앞서 수행한 표준과학 연구 분야 문헌 클러스터링의 마이크로(micro)-레벨 클러스터(195개)를 개별 연구영역(노드, node)으로 간주하였다. 클러스터 쌍의 연결(엣지, edge)은 하나의 클러스터 내 문헌들의 지식기반 분포가 다른 클러스터 내 문헌들의 지식기반 분포와 유사할수록 두터워진다. 지식기반의 분포는 참고문헌들이 각기 속한 WoS 인용주제 메소(meso)-레벨 클러스터의 빈도수 벡터를 이용한 코사인 유사도로 측정하였다.

![표준과학 연구영역 클러스터링 기준으로 구성한 표준과학 연구지형도 (2020~2024년)](Final_Report_MD/%EC%B5%9C%EC%A2%85%EB%B3%B4%EA%B3%A0%EC%84%9C%20%EB%82%B4%EC%9A%A9/std_sci_landscape.png)

위 그림에 나타나는 표준과학 연구지형도 예시에서 노드의 크기는 클러스터 별 문헌수에 비례하며, 노드의 색상은 각 클러스터가 4대 영역 중 어디에 속하는지(자주색은 물리측정, 주황색은 화학소재측정, 노란색은 바이오의료측정, 보라색은 양자기술영역)를 나타낸다. 본 연구지형도는 VOSviewer 기반의 인터랙티브 맵으로도 제공되며, 데이터북의 [연구지형도(인터랙티브 맵)](../website/docs/vosviewer_explorer.html) 페이지에서 확인할 수 있다.

VOSViewer 상에서 활용할 수 있는 대표 지표는 아래와 같으며, 지도에서는 “노드의 크기/색상”에 서로 다른 지표를 선택적으로 겹쳐서(overlay) 확인할 수 있다.

| 지표 | 정의 | 해석 |
| --- | --- | --- |
| 클러스터 규모(노드 크기) | 해당 클러스터에 포함된 고유 문헌 수 | 연구주제의 문헌 규모(활동량) |
| 성장성(상대순위) | 성장 관련 세부지표를 종합한 뒤, 전체 클러스터 대비 상대적 위치를 0–100 범위로 나타낸 값 | 해당 연구주제의 성장 수준(상대) |
| 파급력(상대순위) | 인용 기반 영향력·질적 지표를 종합한 뒤, 전체 클러스터 대비 상대적 위치를 0–100 범위로 나타낸 값 | 해당 연구주제의 학술적 파급 수준(상대) |
| 기술진보 기여도(상대순위) | 특허 연계·기술 확산 관련 지표를 종합한 뒤, 전체 클러스터 대비 상대적 위치를 0–100 범위로 나타낸 값 | 기술진보 기여 수준(상대) |
| 종합 유망도(상대순위) | 성장성·파급력·기술진보 기여도 축을 종합해 산출한 점수의 상대적 위치(0–100) | 종합적으로 “유망”한 연구주제인지(상대) |
| 연구영역 구분(색상) | 클러스터가 속하는 대분류 연구영역(예: 물리·화학소재·바이오의료·양자) | 연구주제의 영역 소속 |
| 기관 특화도(색상) | 특정 기관의 해당 클러스터 내 상대적 특화 지표(예: RTA) | 기관이 그 연구주제에서 상대적으로 강한가 |
| 기관 질적 수준(색상) | 특정 기관의 해당 클러스터 내 질적 성과 지표(예: 상위 10% 영향력 논문 비중) | 기관의 “성과 품질” 수준 |
| 기관 핵심 역량 여부(표시) | 특화·질·규모 조건을 동시에 만족하는 경우 1로 표시(그 외 0) | 기관이 해당 연구주제에서 핵심 역량을 보유하는지 |
