## 글로벌 연구지형도에서의 표준과학 연구 분야

우선 표준연구 영역에 대한 연구지형도 도출에 앞서 전체 과학기술 및 인문사회 영역을 포괄하는 전체 ‘글로벌 연구지형도’를 구성하고, 앞서 식별한 분석용 표준연구 논문 데이터 집합을 글로벌 연구지형도에 ‘겹치기(overlay)’ 매핑함으로써 표준과학 연구 영역이 전체 학문분야에서 차지하는 ‘분포’를 확인하고자 한다.

WoS의 인용 주제(Citation Topics) 메소(meso)-레벨 클러스터(326개)를 개별 연구영역(노드, node)으로 간주하였다. 클러스터 쌍의 연결(엣지, edge)은 하나의 클러스터 내 문헌들의 지식기반 분포가 다른 클러스터 내 문헌들의 지식기반 분포와 유사할수록 두터워진다. 지식기반의 분포는 참고문헌들이 각기 속한 메소(meso)-레벨 클러스터의 빈도수 벡터를 이용한 코사인 유사도로 측정하였다.

아래 그림에서는 문헌의 수(노드 크기)와 표준과학연구 연구 영역 논문 문헌의 비율을 나타내고 있다(노드 색상; 적색에 가까울수록 높으며 청색에 가까울수록 낮음). 글로벌 연구지형도는 VOSviewer 기반의 인터랙티브 맵으로도 제공되며, 데이터북의 [연구지형도(인터랙티브 맵)](/docs/vosviewer_explorer.html) 페이지에서 확인할 수 있다.

[@tbl-global-landscape-indicators]는 글로벌 연구지형도 시각화에서 활용되는 핵심 지표를 요약한다.

| 지표 | 정의 | 해석 |
| --- | --- | --- |
| 메소 클러스터 규모(문헌 수) | 각 메소-레벨 클러스터의 고유 문헌 수(중복 제거 기준) | 해당 메소-레벨 클러스터에 포함된 문헌 규모 |
| 표준과학 연구문헌 비중(색상) | 각 메소-레벨 클러스터의 전체 문헌 중 표준과학 연구 영역 문헌이 차지하는 비율 | 해당 메소-레벨 클러스터가 표준과학 영역에 얼마나 가까운가 |
| 표준과학 전체에서의 비중(색상) | 표준과학 연구 영역 전체 문헌 중 각 메소-레벨 클러스터에 속한 문헌이 차지하는 비율 | 표준과학 전체에서 해당 메소-레벨 클러스터의 상대적 비중 |
| 특정 기관 포트폴리오 내 비중(색상) | 특정 기관의 전체 문헌 중 해당 메소-레벨 클러스터에 속한 문헌이 차지하는 비율 | 해당 메소-레벨 클러스터가 기관 포트폴리오에서 차지하는 비중 |
