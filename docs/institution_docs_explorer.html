기관 문헌 수 탐색기 / Institution Docs Explorer

기관 문헌 수 시계열과 원데이터 표를 함께 확인할 수 있도록 구성하였다.

영역, 축, 기간, 기관을 바꿔 문헌 수 시계열과 원데이터를 함께 확인할 수 있다.

Tip보기 안내
  • 기본: 주요 비교 기관 10개
  • 전체: 개별 기관 전체
  • 합계 포함: BIPM 소속 기관 합계 포함
  • 정렬: 최근 연도 문헌 수 기준 또는 기본순
  • 표시: 상위 5개 / 상위 10개만 빠르게 보기
  • 검색: 기관 선택 목록에서 이름 검색
  • 저장: 현재 차트를 PNG 또는 SVG로 저장

원데이터 표

아래 데이터테이블은 엑셀 원데이터 전체를 long format으로 정리한 것이다. 상단 빠른 선택 버튼과 구분, 영역, 기관, 연도 필터, 헤더 클릭 정렬, 현재 필터 결과 기준 CSV/TSV 내보내기를 지원한다. 기관 표기는 본문 약어 기준으로 정리했다.
