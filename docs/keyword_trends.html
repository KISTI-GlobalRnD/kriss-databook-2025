Appendix B — Keyword Trend Explorer / 키워드 추세 탐색기

본 사업에서는 연구주제(클러스터)별 상위 키워드의 연도별 변화(시계열)를 인터랙티브하게 확인할 수 있도록 탐색기를 구성하였다. 상단 선택 메뉴로 클러스터를 전환할 수 있으며, 범례(legend)에서 개별 키워드 곡선을 켜고 끌 수 있다. 모든 데이터는 키워드 정규화(canonicalisation) 이후 재집계한 키워드 시계열 산출물을 기반으로 한다.

Tip

모든 곡선은 연도·클러스터 단위에서 해당 키워드가 1회 이상 등장한 문헌 수(문서 커버리지)를 나타냅니다. 포인트에 마우스를 올리면 각 용어의 점수(c‑TF‑IDF), 총 등장 빈도(토큰 수), 전체 기간 문서 커버리지(한 문서당 최대 1회), 그리고 해당 연도의 클러스터 문헌 수(분모) 등을 함께 확인할 수 있습니다.

Documents (year) · Number of documents in the selected cluster-year that mention the term at least once.

Cluster Documents (year) · Total number of documents in the selected cluster-year (context for the document counts).

Score · Cluster-specific c‑TF‑IDF weight used to rank keywords (constant across years).

Frequency · Total token occurrences of the keyword within the cluster (aggregated across the full period).

Document Coverage · Number of documents within the cluster that mention the keyword at least once (aggregated across the full period).

Score, Frequency, Document Coverage, and cluster-year document totals appear inside the hover tooltips for each point.
